Panel 1 — Transcription

จับประเด็นตั้งแต่ตอนที่ประชุมกำลังเกิดขึ้น ไม่ต้องรอไฟล์เสียงจบก่อนแล้วค่อยถอดย้อนหลัง เหมาะกับทีมที่ต้องการตาม decision และ action item ให้ทัน

  • Pause Auto-Scroll หยุดเลื่อนชั่วคราวเพื่อย้อนอ่านประเด็นสำคัญได้ โดยระบบยังถอดความต่ออยู่ด้านหลัง
  • แก้ไขข้อความสด แก้ชื่อคน ชื่อโปรเจกต์ หรือศัพท์เฉพาะได้ทันที ก่อนข้อมูลจะถูกใช้ต่อในโน้ตและ AI
  • Cmd+F Search ค้นหาคำในทรานสคริปต์ได้ด้วย shortcut พร้อม highlight สีฟ้า
  • Smart Silence Bypass ช่วงเงียบไม่ควรถูกนับเป็นงาน ระบบช่วยข้าม silence เพื่อลด token และลดข้อความรบกวน
02

Panel 2 — Notebook

Notebook คือพื้นที่ที่ผู้ใช้จดเองระหว่างประชุม แล้วใช้เป็น reference ควบคู่ transcript เพื่อแก้คำผิด ศัพท์เฉพาะ และเติมบริบทสำคัญให้สรุปประชุมแม่นขึ้น

  • Rich Text Editor จัดรูปแบบด้วย Bold, Italic, H1, H2, Bullet List, Quote — toolbar ใช้งานง่ายในตัว
  • Timestamp Sync Click คลิก timestamp เพื่อย้อนฟังวินาทีที่พูดเรื่องนั้น ลดเวลาหาหลักฐานจากไฟล์เสียงยาวๆ
  • Image Size Toggle เก็บภาพสไลด์ ตาราง หรือหน้าจอ demo ไว้คู่กับโน้ต เพื่อไม่ให้บริบทสำคัญหายไป
  • Export โน้ต ส่งต่อสรุปให้ทีม เอาไปแปะใน ticket, doc, หรือรายงานต่อได้โดยไม่ต้องจัดใหม่ทั้งชุด

Panel 3 — AI Assistant

AI ไม่ได้ตอบจาก prompt เปล่าๆ แต่ตอบจากทรานสคริปต์ โน้ต และภาพที่เกิดขึ้นในการประชุมเดียวกัน จึงถามต่อได้แม่นและใช้งานจริงกว่า

  • Preset Prompt ด่วน กดสรุป decision, risk, owner, deadline หรือ action item ได้ทันทีโดยไม่ต้องคิด prompt ใหม่ทุกครั้ง
  • Screen Snapshot Context แนบสไลด์หรือหน้าจอที่แชร์อยู่ให้ AI ใช้ตอบคำถาม ไม่หลุดบริบทจากสิ่งที่ทุกคนกำลังดู
  • Smart Panel Collapse ย่อแผง AI เก็บเป็นแถบบางๆ เพิ่มพื้นที่หน้าจอ กดขยายขึ้นมาคุยอีกครั้งได้ทุกเวลา
  • Export บทสนทนา AI เก็บคำตอบของ AI เป็น Markdown สำหรับทำ meeting recap หรือส่งต่อให้คนที่ไม่ได้เข้าประชุม

พบบ่อย

ข้อมูลเพิ่มเติมเกี่ยวกับการใช้งาน HearJot

ถอดความ Realtime ทำงานอย่างไร? มีดีเลย์ไหม?

HearJot ถอดความตามจังหวะการพูดสด เมื่อ AI วิเคราะห์ช่วงเสียงเสร็จ ข้อความจะปรากฏต่อเนื่องใน Panel 1 ทันที ไม่รอให้ประโยคจบก่อน ผู้ใช้จะเห็นข้อความพิมพ์ตามคำพูดจริงๆ ให้ความรู้สึก real-time ตลอดการประชุม

Pause Auto-Scroll (ปุ่มไอคอนมือ) ใช้งานอย่างไร?

ระหว่างประชุม แอปจะเลื่อนหน้าจอตามประโยคใหม่อัตโนมัติ แต่ถ้าต้องการย้อนขึ้นไปอ่านหรือแก้ไขคำผิด ให้กดปุ่ม ไอคอนรูปมือ เพื่อล็อกหน้าจอ — ระบบถอดความยังทำงานต่อ แต่หน้าจอจะไม่กระตุกหนีสายตา ช่วยให้ทำงานโดยไม่เสียสมาธิ

แก้ไขข้อความในทรานสคริปต์ (Panel 1) ทำได้อย่างไร?

เอาเมาส์ hover ไปที่กล่องข้อความที่ต้องการแก้ไข จะมี ไอคอนดินสอ ปรากฏขึ้นที่มุมขวา คลิกเพื่อเข้าสู่โหมดแก้ไข พิมพ์แก้คำผิดได้เลย แล้วกด Enter หรือคลิกนอกกล่องเพื่อบันทึก — ทำได้ทันทีขณะที่การประชุมยังดำเนินอยู่โดยไม่หยุดการถอดความ

Teams Sync ทำงานอย่างไร? ต้อง Login Teams ไหม?

ไม่ต้อง Login ค่ะ HearJot ใช้การดักรับ Desktop Audio Loopback และ Microphone Input พร้อมกัน เพียงเปิดสวิตช์ Teams Sync แล้วเลือกหน้าต่าง Teams จาก Source Picker ระบบจะจับเสียงจากทั้งไมค์คุณและเสียงสายประชุมเข้า Panel 1 โดยอัตโนมัติ มีแถบระดับเสียง (Mic Level Indicator) แสดงสถานะทั้งสองช่องแบบ real-time

Smart Silence Bypass ช่วยประหยัด API Token ได้จริงไหม?

จริงครับ! ระบบตรวจจับพลังงานเสียง (RMS) แบบ real-time ถ้าช่วงใดเงียบหรือไม่มีเสียงพูด จะ ข้ามไปโดยอัตโนมัติ ไม่ส่งให้ AI วิเคราะห์ ช่วยลดค่าใช้จ่าย API และทำให้ทรานสคริปต์สะอาด ไม่มีบรรทัดว่างๆ สะสมจากช่วงเงียบ

Timestamp Sync Click ในโน้ตใช้งานอย่างไร?

ทุกย่อหน้าในโน้ต Panel 2 จะมีป้ายเวลาเสียง เช่น [00:30] ติดอยู่ เมื่อกลับมาอ่านโน้ตในภายหลัง แค่คลิกป้ายเวลานั้น Audio Player ด้านล่างจะวิ่งไปยังวินาทีนั้นและเล่นเสียงให้ฟังทันที — ไม่ต้องเลื่อนหาเองเลย ช่วยประหยัดเวลาตรวจสอบเสียงประชุมย้อนหลังได้มาก

Panel 3 AI Assistant ถาม-ตอบได้แค่ไหน? มีความจำไหม?

AI ใน Panel 3 ขับเคลื่อนด้วย Gemini ที่รู้บริบทการประชุมทั้งหมดจากทรานสคริปต์ใน Panel 1 สามารถสรุปประเด็น, ถามเจาะลึก, ทำ Action Items, หรือวิเคราะห์ได้เลย ระบบรองรับความจำบทสนทนา สูงสุด 20 เซสชัน ในครั้งเดียว และมีปุ่ม Preset Prompt ลัดให้กดด่วนโดยไม่ต้องพิมพ์คำสั่งยาวๆ

Screen Snapshot Context ใน AI Chat ทำงานอย่างไร?

ระหว่างประชุมออนไลน์ที่มีการแชร์สไลด์หรือวิดีโอ คุณสามารถกดปุ่ม Snapshot เพื่อให้แอปถ่ายภาพหน้าจอ ณ ขณะนั้นและแนบเข้าไปในแชทกับ AI ใน Panel 3 ได้โดยตรง — AI จะอ่านข้อมูลจากสไลด์นั้นและนำมาประกอบการสรุปหรือตอบคำถามได้แม่นยำยิ่งขึ้น

Batch Audio Import ถอดความไฟล์ที่บันทึกไว้แล้วได้ไหม?

ได้ครับ! ลากไฟล์เสียงที่บันทึกไว้ใส่แอปได้โดยตรง ระบบจะถอดความแบบ Batch และแสดงแถบความคืบหน้า (%) ขณะประมวลผล พร้อม Audio Player ด้านล่างที่ sync กับทรานสคริปต์ — เหมาะสำหรับย้อนถอดเสียงการประชุมที่อัดเก็บไว้แล้ว

Global Hotkeys ตั้งค่าอย่างไร ใช้งานได้ขณะเปิดแอปอื่นไหม?

ได้เลยครับ! Global Hotkeys ของ HearJot ทำงานระดับ System-wide หมายความว่าแม้จะกำลังพิมพ์ใน Word, Notion หรือเปิด Teams อยู่ ก็ยังกดคีย์ลัดเพื่อ Toggle เปิด/ปิดไมค์ หรือ Snapshot ภาพหน้าจอ ได้ทันที ตั้งค่าคีย์ได้เองในหน้า Settings ของแอป

สามารถแชร์โน้ตให้คนอื่นได้ไหม?
