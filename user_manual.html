1. การเริ่มต้นตั้งค่า API Key & เลือก AI Model

ในการเริ่มใช้งาน HearJot สิ่งแรกที่ต้องทำคือการป้อนรหัสเชื่อมโยงปัญญาประดิษฐ์ (API Key) เพื่อให้สมองกลของ Co-Pilot และระบบประมวลผลคำพูดถอดความเริ่มทำงานได้อย่างเต็มประสิทธิภาพ โดยระบบจะเก็บค่านั้นไว้อย่างปลอดภัยในเครื่องของคุณ

🔒 ข้อมูลความเป็นส่วนตัวของคุณ

HearJot เป็นแอปพลิเคชันที่ทำงานอยู่บนเครื่องของคุณแบบ 100% ตัวแอปจะไม่มีการเก็บประวัติ คีย์ หรือส่งไฟล์เสียงประชุมออกไปยังเซิร์ฟเวอร์ภายนอกของบุคคลที่สาม ยกเว้นการยิงตรงไปยังผู้ให้บริการโมเดลที่คุณเลือกใช้เองเท่านั้น

การปรับเลือก AI Model

แอปพลิเคชันเปิดโอกาสให้ผู้ใช้งานสลับโมเดลในการประมวลผลได้จากรายการดรอปดาวน์บริเวณเมนูตั้งค่า ซึ่งการเลือกสลับโมเดลนี้จะส่งผลโดยตรงต่อทั้งแผงประมวลผลถอดความ (Panel 1: Transcribe) และแผงถามตอบสรุปข้อมูล (Panel 3: AI Assistant Co-Pilot) ร่วมกัน เพื่อให้การตีความน้ำเสียงและการวิเคราะห์ข้อมูลมีความสอดคล้องกันตลอดทั้งเซสชัน

2. การติดตั้งและการจัดการสิทธิ์ความปลอดภัยในระบบ (macOS)

บนระบบปฏิบัติการ macOS ความเป็นส่วนตัวเป็นเรื่องสำคัญยิ่ง เพื่อให้ระบบสามารถดึงเสียงสตรีมอินพุตมาถอดความสดได้ HearJot จำเป็นต้องได้รับสิทธิ์อนุญาตพิเศษสองส่วนในการรันแอปครั้งแรก

การติดตั้งโปรแกรม

  • สำหรับ macOS: ดับเบิ้ลคลิกไฟล์ .dmg ที่ดาวน์โหลดแล้วลากไอคอนแอป HearJot วางลงในโฟลเดอร์ Applications
  • สำหรับ Windows: ดับเบิ้ลคลิกเปิดไฟล์ตัวติดตั้ง .exe และดำเนินการติดตั้งตามขั้นตอนปกติจนเสร็จสิ้นเพื่อเริ่มต้นใช้งาน

การตั้งค่าสิทธิ์ความเป็นส่วนตัว (macOS Permissions)

เมื่อเริ่มใช้งานการบันทึกหน้าต่างประชุมสดเป็นครั้งแรก ระบบปฏิบัติการจะเด้งถามสิทธิ์ ให้ผู้ใช้เลือกตอบ "ตกลง" (OK/Allow) เสมอสำหรับสิทธิ์เหล่านี้:

  1. Screen & System Audio Recording (การจับภาพหน้าจอและเสียงระบบ): สำหรับดักจับสตรีมเสียงการพูดของฝ่ายตรงข้ามในทีม Microsoft Teams/Zoom
  2. Microphone (การเข้าถึงไมโครโฟน): สำหรับบันทึกเสียงพูดของคุณผ่านไมโครโฟนเครื่อง

🚨 วิธีแก้ปัญหา "สิทธิ์ผีหลอก" (TCC Dead Toggle) บน Mac

บ่อยครั้งหลังจากติดตั้งเวอร์ชันใหม่ สิทธิ์ในระบบ macOS อาจเกิดอาการบล็อกตัวแอปแบบเงียบๆ (เปิดสวิตช์เป็นสีฟ้าแล้ว แต่แอปยังดึงเสียงไม่ได้) คุณสามารถแก้ปัญหานี้ได้อย่างรวดเร็วโดยการล้างสิทธิ์ที่ค้างอยู่ผ่านแอป Terminal โดยคัดลอกชุดคำสั่งด้านล่างนี้ไปสั่งรัน

Terminal — macOS Permissions Reset
tccutil reset ScreenCapture com.hearjot.assistant tccutil reset Microphone com.hearjot.assistant

*หลังจากรันคำสั่งด้านบน ให้ปิดและเปิดแอป HearJot ขึ้นมาใหม่อีกครั้ง แอปจะแสดงหน้าต่างเด้งตอบรับข้อกำหนดสิทธิ์ใหม่อีกรอบ ให้กดคลิกอนุมัติ สตรีมเสียงก็จะไหลกลับมาทำงานได้เป็นปกติครับ

3. การเริ่มต้นใช้บริการบันทึกสิทธิ์เซสชันประชุม (Live Listening)

การเปิดกล่องสัญญาณเสียงและเริ่มต้นประชุมทำได้โดยกดปุ่มเริ่มทำงานอัจฉริยะในหน้าหลัก แนะนำลำดับขั้นตอนการรันโปรเซสที่ถูกต้องดังนี้:

1. เลือกแหล่งเสียงประชุม

กดคลิกที่ปุ่มตัวเลือก Source Picker เพื่อระบุหน้าต่างที่ต้องการจับสัญญาณเสียง เช่น หน้าต่างโปรแกรม Microsoft Teams, แอปประชุม Zoom หรือเลือกจับทั้งหน้าจอแบบเต็มจอ

เลือกแหล่งสัญญาณเสียง / Select Audio Source

Select Audio Source

Choose the window or screen you want to record.

Cancel
แผนภาพจำลองหน้าต่างเลือกแอปพลิเคชันห้องประชุม (สามารถคลิกเลือกช่องด้านบนเพื่อทดสอบการตอบสนองได้ครับ)

2. ตรวจสอบ Teams Sync & Mic

เปิด/ปิดสวิตช์ Teams Sync และ Microphone บนหน้า UI ให้สอดคล้องกับสภาพการใช้งานจริงของคุณ โดยมีจุดสังเกตสำคัญคือ เกจแถบวัดระดับเสียงไมโครโฟน (Audio Level Meter) จะยังไม่ขยับขยายหรือตอบสนองในตอนแรก มันจะเริ่มเคลื่อนไหวตามจังหวะรับเสียงหลังกดเริ่มเซสชัน (Start Listening) เท่านั้น

3. กดเริ่มและเซฟพิกัดไฟล์

คลิกปุ่มสีน้ำเงิน "Start Listening" แอปจะเด้งหน้าต่างให้ผู้ใช้กำหนดที่ตั้งจัดเก็บไฟล์บันทึกเสียงดิบ .webm ทันที โดยหลังจากระบุแล้วระบบจะสร้างไฟล์และเริ่มอัดและเริ่มมีสัญญาณแถบระดับเสียงขยับขึ้นลงพร้อมทำการถอดความทันที

Batch Audio Import สำหรับบันทึกเสียงย้อนหลัง

หากคุณมีไฟล์บันทึกเสียงการประชุมเก็บไว้อยู่แล้ว เช่น ไฟล์เสียงอัดจากสมาร์ตโฟนพกพา หรือไฟล์บันทึกเสียงที่เก็บถาวรไว้จากการประชุมครั้งก่อนๆ คุณไม่จำเป็นต้องบันทึกสดเพื่อถอดความ เพียงกดปุ่ม "Load Audio" (ไอคอนรูปแฟ้มเสียง 📁) เพื่ออัปโหลดไฟล์เสียงเข้ามาถอดความในระบบ โดยแอปพลิเคชันจะแสดงเปอร์เซ็นต์ความคืบหน้าในการประมวลผลบนหน้าจอให้เห็นอย่างชัดเจน

ล็อกหน้าจอถอดความด่วน

คลิกปุ่มไอคอนตัวเลขเรืองแสงในจอจำลองด้านข้าง เพื่อทำความเข้าใจการทำงานแบบพรีเมียมในทุกมิติของหน้าต่างโปรแกรมได้เลยครับ

รายละเอียดการใช้งานฟีเจอร์เชิงลึก

แผงที่ 1: Transcription (ถอดความสดตามประโยคพูด)

  • ถอดความแบบแบ่งช่วงเวลาอัจฉริยะ: ระบบจะประมวลผลสัญญาณเสียงประชุมและส่งคำสั่งถอดความออกมาเป็นชุดข้อความย่อยทุกๆ ช่วงเวลาประมาณ 10 วินาที เพื่อให้คำสนทนาค่อยๆ ทยอยปรากฏขึ้นมาบนจออย่างสม่ำเสมอโดยผู้ใช้ไม่ต้องรอจนจบชั่วโมงประชุม ช่วยให้อ่านและติดตามประเด็นความคืบหน้าได้ตลอดเซสชัน
  • Pause Auto-Scroll (ปุ่มไอคอนรูปมือ 🖐️): ตามค่าเริ่มต้น แผงจะเลื่อนลงไปประโยคใหม่ด้านล่างสุดโดยอัตโนมัติ หากคุณอยากเลื่อนขึ้นไปอ่านหรือแก้ไขคำพิมพ์ผิดด้านบน ให้คลิกปุ่มไอคอนรูปมือเพื่อหยุดการเลื่อนชั่วคราว เมื่ออ่านเสร็จให้กดอีกครั้งเพื่อให้แผงไหลตามเสียงดังเดิม
  • Inline Segment Editing (แก้ไขคำผิดสด): หากพบบอร์ดพิมพ์แปลคำผิดระหว่างประชุม ให้เลื่อนเมาส์ชี้ไปที่บล็อกประโยคนั้นแล้วคลิกที่ "ปุ่มดินสอ" ✏️ หรือดับเบิ้ลคลิก เพื่อทำการแก้คำพิมพ์ผิดในกล่องได้ทันทีขณะที่ระบบอัดเสียงยังถอดความสดต่อไป
  • Cmd+F Search (ระบบค้นหาเรียลไทม์): ค้นหาคำสำคัญที่ถูกพูดในที่ประชุมได้ทันทีด้วยคีย์บอร์ดช็อตคัต ระบบจะระบายไฮไลท์สีฟ้าที่คำเหล่านั้นทันทีให้หาง่าย
  • Smart Silence Bypass (ตรวจจับเสียงเงียบ): ระบบกรองสัญญาณอัจฉริยะจะช่วยตรวจหาช่วงเวลาเงียบเสียงหรือไม่มีการสนทนาและสกัดไม่ให้ยิงสตรีมความเงียบดังกล่าวไปประมวลผลกับทาง API ช่วยลดภาระการใช้ทรัพยากรแบนด์วิดท์ และเซฟจำนวน Token ของบริการโมเดล AI ของคุณได้อย่างมีประสิทธิภาพ

แผงที่ 2: Notebook (สมุดโน้ตซิงค์เวลาคลิกฟังย้อนหลัง)

  • Formatting Rich Text Toolbar: สามารถพิมพ์จัดฟอร์แมตเอกสารได้ยืดหยุ่นเหมือนแอปโน้ตชั้นนำ คีย์ H1, H2, Bold, Italic และ Bullet List มีครบถ้วน
  • Timestamp Sync Click (ป้ายเวลาซิงค์เสียง): ในขณะที่จดบันทึก คุณจะต้องกดคีย์ Shift + Enter เพื่อขึ้นบรรทัดใหม่และสั่งระบุรหัสป้ายเวลา [00:15] ซิงค์กับวินาทีประชุมให้โดยอัตโนมัติ (ในกรณีที่กดปุ่ม Enter แบบปกติ จะเป็นการขึ้นย่อหน้าใหม่ทั่วไปแบบคลีนๆ ปราศจากป้ายเวลาซิงค์เสียง) หลังจากโน้ตเสร็จสิ้น คุณสามารถเอาเมาส์คลิกจิ้มป้ายเวลานั้นๆ เพื่อให้แอปพลิเคชันข้ามไปเปิดเสียงย้อนหลังตรงวินาทีสำคัญที่คุยกันตอนจดจุดนั้นได้ทันที
  • Instant Screen Snapshot & Resize Handles: เมื่อกดปุ่ม Snapshot 📷 (หรือปุ่มคีย์ลัด ⌘+Shift+S) หน้าจอการประชุมสดจะถูกแคปเจอร์เป็นรูปภาพและนำเข้ามาแทรกไว้ในสมุดโน้ตแผง 2 พร้อมปักป้ายเวลา ณ วินาทีนั้นๆ ให้อัตโนมัติ โดยผู้ใช้สามารถคลิกเลือกที่รูปภาพดังกล่าวแล้วลาก Handle สี่เหลี่ยมสีน้ำเงินมุมขวาล่าง เพื่อย่อขยายขนาดและมิติสัดส่วนภาพแนบได้อย่างสวยงามและอิสระ
  • Toggle Image Size (สลับมุมมองขนาดภาพ 🖼️): คลิกปุ่มไอคอนรูปภาพซ้อน 🖼️ บนทูลบาร์ของแผงโน้ต เพื่อสลับมุมมองการแสดงผลรูปภาพทั้งหมดภายในเอกสารระหว่าง "ขนาดกะทัดรัด (Compact / Thumbnail)" และ "ขนาดดั้งเดิม (Full Size)" ได้ในคลิกเดียว สะดวกอย่างยิ่งเมื่อเอกสารมีรูปภาพแนบจำนวนมากและต้องการซ่อนภาพชั่วคราวเพื่อไล่อ่านโน้ต หรือจะคลิกที่ตัวรูปภาพเพื่อขยาย/ย่อแบบแยกเฉพาะภาพ (Individual Toggle) ก็ย่อมได้
  • Mini Mode (โหมดโน้ตย่อ Compact): สามารถคลิกไอคอนยุบแผง (Mini Mode Button) บริเวณด้านขวาของทูลบาร์แถบแผง 2 เพื่อสลับตัวแอปพลิเคชันเข้าสู่หน้าจอกระชับขนาดเล็กกะทัดรัด ตัวระบบจะสลับปิดย่อแผงถอดความ (Panel 1) และแผง Co-Pilot (Panel 3) ทิ้งทั้งหมดเหลือเพียงช่องพิมพ์จดบันทึกแผง 2 แบบเดี่ยวๆ และสั่งระบบ **"ปักหมุดตรึงหน้าต่างให้อยู่บนสุดเสมอ" (Always on Top)** ให้อย่างราบรื่น เพื่อให้คุณซ้อนวางหน้าโน้ตแอปทับหน้าจอโปรแกรมประชุม Zoom/Teams อื่นๆ ได้ทันทีโดยไม่ถูกบดบัง อีกทั้งรองรับการกดสลับรูปแบบการจัดวาง (Orientation) แนวตั้ง (Portrait) และแนวนอน (Landscape) เพื่อความอิสระและยืดหยุ่น

แผงที่ 3: AI Co-Pilot (ผู้ช่วยสรุปวิเคราะห์การประชุม)

  • Response Style Presets (การตั้งค่าสไตล์คำตอบ 🪄): ผู้ใช้สามารถคลิกปุ่มไอคอนไม้กายสิทธิ์ 🪄 บนหัวข้อแผง Co-Pilot เพื่อเรียกเปิดหน้าต่าง "Manage Custom Prompts & Presets" ในการเลือกและปรับแต่งลักษณะของสไตล์การตอบกลับตามแบบฉบับของคุณ (เช่น ตอบกลับเฉพาะหัวข้อสำคัญแบบกระชับ, ใช้โทนทางการ, หรือแยกแยะ Action Items) ระบบมาพร้อมพรีเซ็ตมาตรฐานและช่วยให้คุณสร้างพรีเซ็ตแบบกำหนดเอง (Custom Presets) ได้ เพื่อประมวลผลคำตอบของ AI ได้ตรงตามเป้าหมายขององค์กรอย่างรวดเร็ว

  • Preset Prompt สรุปด่วน: มีกลุ่มปุ่มลัดคำสั่งด่วนด้านล่างแผง เช่น "สรุป Action Items", "สรุปงบการเงิน" หรือ "วิเคราะห์ใจความหลัก" กดเพียงครั้งเดียว AI จะไปกวาดข้อมูลคำพูดในแผง 1 มาทำสรุปผลวิเคราะห์ให้คุณในไม่กี่วินาที โดยจะอิงตามสไตล์คำตอบที่คุณเปิดเลือกใช้งานไว้
  • แหล่งข้อมูลบริบทสำหรับ AI Q&A Chat: เมื่อผู้ใช้พิมพ์แชทสอบถามหรือสั่งวิเคราะห์ประเด็นคำถามในแผง 3 ระบบ AI อัจฉริยะจะทำการกวาดรวมข้อมูลแวดล้อมรอบด้านมาทำเป็นบริบทวิเคราะห์ร่วมกันเพื่อความสมบูรณ์แบบของคำตอบ ซึ่งได้แก่:
    1. เนื้อหาตัวอักษรและโครงสร้างจดบันทึกปัจจุบันในแผง 2 (Notebook)
    2. ทรานสคริปต์ความยาวคลื่นเสียงที่ถอดคำพูดได้สำเร็จบางส่วนหรือทั้งหมดในแผง 1 (Transcription) ซึ่งกวาดดึงประเด็นตามคำสำคัญ (Keywords) และกรอบเวลาที่สอดคล้อง
    3. รูปภาพแคปเจอร์หน้าจอ (Screen Snapshots) ที่แทรกอยู่ในแผง 2 โดยผู้ใช้งานต้องเปิดใช้งานปุ่ม Toggle Screen Snapshots (ไอคอนรูปภาพ 🖼️ บนหัวข้อแผง 3) เพื่อให้ AI อนุมัติสิทธิ์การดึงพิกัดภาพไปประมวลผลเชิงทัศนศิลป์ด้วย
  • Panel Quick Collapse & Expand: สามารถพับย่อขยายความกว้างของแผงทำงานทั้งหมดได้ยืดหยุ่น โดยการแดรกขยับแถบคั่นสเกลแผง หรือคลิกที่ปุ่มพับแผงด่วนของ Co-Pilot ด้านขวาสุด เพื่อพับปิดแผงทำงานเหลือเป็นแนวแท่งทึบบางเฉียบ เพิ่มเนื้อที่หน้ากระดาษแผงตรงกลางให้โดดเด่นสูงสุด

5. การบันทึกและแบ่งปันแฟ้มเอกสาร (Save & Export Packages)

หลังจากเสร็จสิ้นวาระการประชุม HearJot นำเสนอเทคโนโลยีการเก็บไฟล์ข้อมูลแบบแพ็กเกจรวมเลเยอร์ที่มีประสิทธิภาพสูงเพื่อความสะดวกสบายในการส่งมอบงานต่อให้ทีม

การบันทึกเซสชันในรูปแบบ "Single Package"

เมื่อกดบันทึกผลงานผ่านปุ่ม Save หรือ Save As ในแผงสไลด์ด้านข้าง ระบบจะมัดรวมเอาไฟล์ทั้ง 3 ข้อมูลหลักดังนี้เข้าเป็นไฟล์เดียว:

  1. ไฟล์เสียงบันทึกการประชุมดิบ (.webm): ปรับแต่งบิตเรตคมชัดและลดขนาดไฟล์ให้เปิดฟังชัดเจน
  2. ชุดข้อมูลทรานสคริปต์คำถอดความ (.json): บรรจุช่วงเวลากำกับตัวอักษรทุกช่วงประโยค
  3. สมุดโน้ต Rich Text จดสรุปของคุณ (.html/.json): รวมถึงลิ้งก์พิกัดภาพประกอบที่คุณจัดตกแต่งไว้

เมื่อเพื่อนร่วมงานของคุณได้รับไฟล์แพ็กเกจนี้ไปเปิดใช้งานต่อบนโปรแกรม HearJot บนเครื่องของเขา หน้าจอ 3 แผงทำงานจะถูกโหลดแสดงขึ้นมาครบถ้วนตามเลเยอร์ รวมถึงปุ่มป้ายเวลาเหลืองก็ยังสามารถกด Seek กระโดดฟังช่วงเสียงการประชุมได้อย่างคมชัดเหมือนที่ผู้จัดจดทำไว้ทุกประการ

การส่งออกเอกสารภายนอก (Markdown & Text Exporter)

นอกจากรูปแบบไฟล์รวมของระบบแล้ว คุณยังสามารถสั่งแยกไฟล์ส่งออกข้อมูลเฉพาะส่วนเพื่อนำไปเขียนรายงานหรือโพสต์ลงสแลคได้ง่ายๆ:

  • Notebook Exporter: กดปุ่มไอคอนดาวน์โหลดด้านบนสมุดโน้ตเพื่อเลือกเซฟข้อความจดบันทึกเป็นฟอร์แมตเอกสาร Markdown .md หรือ Text .txt คลีนๆ ปราศจากโค้ด HTML ตกค้าง
  • AI Chat Exporter: คัดลอกบทสนทนาประวัติการคุยตอบโต้เชิงลึกกับ Co-Pilot ไปใช้งานต่อภายนอกได้อย่างรวดเร็วในคลิกเดียว

6. Global Hotkeys และทริกควบคุมระดับโปร (Power User Guide)

สำหรับการเข้าถึงการทำงานที่รวดเร็วทันใจ HearJot ได้จัดเตรียมระบบคีย์ลัดภายนอกที่สามารถเรียกใช้งานได้ตลอดเวลาแม้ว่าผู้ใช้จะกำลังพรีเซนต์งานหรือทำงานอยู่บนแอปพลิเคชันอื่นก็ตาม

⌘ + Shift + M

เปิด/ปิดสวิตช์อินพุตเสียงไมโครโฟนด่วน (Toggle Mic): ช่วยป้องกันเสียงสอดแทรกหลุดเข้าไปในระบบโดยไม่ได้ตั้งใจขณะที่คุณไม่ได้สนทนาหรือกำลังฟังผู้อื่นพรีเซนต์

⌘ + Shift + S

บันทึกภาพหน้าจอช่วงประชุมด่วน (Snapshot): เพื่อสกรีนช็อคหน้าจอภาพประชุมที่กำลังนำเสนอ ณ เสี้ยววินาทีนั้นๆ และส่งฝังรูปแนบเข้าสู่หน้าสมุดโน้ตแผง 2 (Notebook) พร้อมประดับรหัสป้ายเวลา (Timestamp Badge) กำกับให้อย่างสมบูรณ์แบบโดยอัตโนมัติ

เทคนิคระดับโปรในการจดโน้ต

  • Obsidian Bullet List Trigger: ใน Panel 2 สมุดโน้ต หากคุณพิมพ์เครื่องหมายขีดลบ - หรือสัญลักษณ์ดอกจัน * แล้วกดปุ่ม **Space (เว้นวรรค)** ระบบจะแปลงสัญลักษณ์เหล่านั้นเป็นกล่องรายการแบบจุดวงกลม (Bullet List) ให้อย่างสวยงามทันทีโดยไม่ต้องคลิกปุ่มบนทูลบาร์
  • Double Channel Audio Visualizer (หลังกดเริ่มบันทึก): หลังจากกดคลิกเริ่มบันทึกเซสชันแล้ว ให้สังเกตแถบความถี่เสียงไมค์เทียบกับเสียงของระบบคอมพิวเตอร์ที่เริ่มขยับตามคลื่นเสียงพูดจริง ซึ่งกราฟวัดเสียงที่เริ่มเคลื่อนไหวนี้จะรับประกันว่าข้อมูลเสียงของคุณและคู่สนทนากำลังไหลเข้าสู่การประมวลผลถอดความในแผง 1 อย่างไร้ที่ติ

HearJot มีกลไกส่งสัญญาณประมวลผลและถอดความแบบแบ่งช่วงเสียง (Segment) ทุกๆ ประมาณ 10 วินาที ส่งผลให้บทสนทนาที่ถูกพูดจะได้รับการประมวลคำถอดความเสร็จและทยอยปรากฏขึ้นบนแผงที่ 1 ภายในเวลาเฉลี่ยประมาณ 10 วินาที เพื่อให้คุณไล่เรียงอ่านและติดตามสรุปความคืบหน้าของการสนทนาได้อย่างราบรื่นและเป็นระบบโดยข้อมูลไม่ตกหล่นครับ

เหตุใดการคลิกที่ป้ายเวลากระโดดข้ามช่วงเสียงจึงไม่ทำงานเป็นบางครั้ง?

ป้ายเวลาดังกล่าวจะดักสัญญาณเสียงจากเครื่องเล่นเสียงดิบด้านล่างแอป หากคุณเผลอกดปุ่ม Unload Audio หรือล้างไฟล์เสียงประชุมดิบออกจากตัวระบบ ป้ายเวลาสีเหลืองจะไม่สามารถอ้างอิงพิกัดตำแหน่ง Seek ได้ และจะแสดงไอคอนล็อกไว้ แนะนำให้ทำความสะอาดและจัดเก็บไฟล์ .webm ไว้คู่กันในโฟลเดอร์เสมอ

ไมค์สปีกเกอร์ของเพื่อนในโปรแกรม Teams ไม่ถูกดักถอดประโยค แก้ไขอย่างไร?

ตรวจดูสวิตช์ Teams Sync บนหน้า UI เสมอ และหากเปิดอยู่แล้วเสียงยังไม่มา ให้ใช้ Source Picker เพื่อทำการเคลียร์และเลือกหน้าต่างของโปรแกรม Microsoft Teams ใหม่อีกครั้ง และตรวจสอบสิทธิ์การแคปเจอร์สกรีนของระบบ macOS ให้เรียบร้อยตามคำแนะนำในหมวดที่ 2 ครับ

ปุ่ม Save และ Save As แตกต่างกันอย่างไรบ้าง?

ปุ่ม **Save** จะทำการบันทึกและเขียนข้อมูลทับลงไปยังไฟล์เดิมที่คุณสร้างและระบุจุดจัดเก็บพิกัดในตอนเริ่มต้น ส่วนปุ่ม **Save As** จะให้สิทธิ์ผู้ใช้ตั้งชื่อใหม่หรือคัดลอกเซสชันปัจจุบันเพื่อสร้างเป็นแฟ้มงานแพ็กเกจใหม่ เพื่อแบ่งโครงสร้างบันทึกเป็นหลายๆ รูปแบบได้ตามความต้องการ
